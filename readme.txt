YOUR ANTIBIOTIC ASSISTANT - installable Android app (PWA)

Option A (fastest, free): host this folder on any HTTPS host, then install from Chrome.
 1) Netlify Drop (app.netlify.com/drop) or GitHub Pages: upload this whole folder.
 2) Open the https link in Chrome on the Android phone.
 3) Menu (3 dots) > Install app / Add to Home screen.
 The app then opens full screen and works offline after the first load.

Option B (real APK): after hosting, open pwabuilder.com, paste the link, choose Android, download the package.

Notes
 - Saved cases and notes are stored on the phone (localStorage); use Backup in the app.
 - Excel upload needs internet the first time (CSV works offline).
 - Content is DRAFT: verify doses before use.
